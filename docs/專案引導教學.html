TradingSpringSecurity

Spring Security + JWT · 訂單 CRUD／冪等 · USER／ADMIN 授權

Java 21 Spring Boot 3.2 Port 8080 JWT HS256 JPA + H2 無前端 無 Kafka／Redis

60 秒速覽 — 這專案在幹嘛？

一句話：用 Spring Security + JWT（無 Session）保護訂單 CRUD，示範註冊／登入、角色授權（USER／ADMIN）、以及 clientOrderId 冪等下單。

幹線 A · 認證

POST /api/auth/register → login 拿 JWT → 之後帶 Authorization: Bearer …

  • 密碼：BCrypt
  • Token：HS256，STATELESS
  • Filter 重建 SecurityContext

幹線 B · 訂單

建單／查詢／取消／刪除；DELETE 僅 ADMIN

  • 冪等鍵 clientOrderId
  • 重複 → 409
  • 資料落 H2（JPA）
沒有前端。用 curl／Swagger 驗證。對照 TradingSpringBoot：有 Security／分層，無 Kafka／Redis。

運作規則（必記）

  1. 無狀態 API — Session 關閉；每個請求靠 JWT 重建 SecurityContext。
  2. Controller 不含商業邏輯 — 只做 HTTP、@Valid、委派 Service、回傳 DTO。
  3. 授權集中在 SecurityConfig — 公開路徑 permitAll；DELETE /api/v1/orders/** → hasRole("ADMIN")；其餘需 authenticated()。
  4. 冪等靠 clientOrderId UNIQUE — Service 先查再寫；重複 → 409 DUPLICATE_ORDER。
  5. 密碼只存 BCrypt 雜湊 — 登入用 AuthenticationManager，成功後簽發 Token。

5 分鐘實作驗證

啟動

cd D:\ClaudeCode\TradingSpringSecurity
. .\scripts\env.ps1
.\gradlew.bat bootRun

註冊

curl -X POST http://localhost:8080/api/auth/register `
  -H "Content-Type: application/json" `
  -d "{\"username\":\"alice\",\"password\":\"password123\"}"

預期 201。

登入拿 Token

curl -X POST http://localhost:8080/api/auth/login `
  -H "Content-Type: application/json" `
  -d "{\"username\":\"alice\",\"password\":\"password123\"}"
$TOKEN = "<貼上 token>"

建單

curl -X POST http://localhost:8080/api/v1/orders `
  -H "Authorization: Bearer $TOKEN" `
  -H "Content-Type: application/json" `
  -d "{\"clientOrderId\":\"ORD-001\",\"symbol\":\"AAPL\",\"side\":\"BUY\",\"quantity\":10,\"price\":150.00}"

預期 201，status = NEW。

冪等 409 ＋ 無 Token 401

同一 clientOrderId 再打一次 → 409。curl http://localhost:8080/api/v1/orders（無 Header）→ 401。

測試全綠

.\scripts\check.ps1
# 或 .\gradlew.bat check
自測口訣：建單 201、無 token 401、驗證失敗 400、冪等 409、非 ADMIN 刪除 403、ADMIN 刪除 204。
