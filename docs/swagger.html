Auth JWT · Order CRUD／冪等 · 角色 USER／ADMIN · Spring Boot 3.2 · Java 21 · H2（無 Kafka／Redis，對照 TradingSpringBoot）

啟動.\gradlew.bat bootRun
Port8888（application.yml 實際值；不是 8080，部分舊文件誤寫）
OpenAPI JSONhttp://localhost:8888/v3/api-docs
Swagger UIhttp://localhost:8888/swagger-ui.html
H2 Consolehttp://localhost:8888/h2-console（JDBC jdbc:h2:mem:tradingdb，帳號 sa，密碼空白）
驗證.\scripts\check.ps1（或 .\gradlew.bat check）

API 分組（實際 Controller）

  • Auth：POST /api/auth/register、POST /api/auth/login
  • Orders：POST /api/v1/orders（冪等）、GET /api/v1/orders（分頁）、GET /{id}、PATCH /{id}/cancel、DELETE /{id}
  • 角色：一般操作 USER；刪除等管理操作需 ADMIN。

認證與範例流程

  • JWT（HS256）：帳號需先 POST /api/auth/register 註冊（無內建帳號）。
  • POST /api/auth/login 取得 token，點右上 Authorize 輸入 Bearer <token>。
  • 範例：register → login → POST /api/v1/orders 下單 → PATCH /{id}/cancel 取消。

注意：本專案實際埠為 8888（見 application.yml 的 server.port: 8888），文件若寫 8080 為誤植。 本頁載入 http://localhost:8888/v3/api-docs，請先啟動應用。若以 file:// 直接開啟本頁而無法載入， 請改用 http://localhost:8888/swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
