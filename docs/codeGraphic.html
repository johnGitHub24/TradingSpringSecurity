Filter — 安全過濾鏈

  • STATELESS：無 Session；身分靠 JWT 重建。
  • 公開：/api/auth/**、Swagger、health、h2-console。
  • DELETE /api/v1/orders/** 需 ADMIN；其餘需認證。
  • 未認證 → 401（HttpStatusEntryPoint）。
flowchart LR R[HTTP Request] --> F[JwtAuthenticationFilter] F --> A{authorizeHttpRequests} A -->|permitAll 公開路徑| C[Controller] A -->|DELETE orders + ADMIN| C A -->|anyRequest authenticated| C A -->|未認證| U[401] A -->|無 ADMIN| X[403] C --> S[Service]

JWT Filter 掛在 UsernamePasswordAuthenticationFilter 之前（SecurityConfig）。無效 Token 不在 Filter 硬擋，交由後續授權規則。

JWT — 簽發與驗證

  • 註冊：BCrypt 存密碼；登入：AuthenticationManager → 簽發 HS256。
  • Token 含 username + roles claim；預設約 1 小時（app.jwt.*）。
  • 後續請求：Authorization: Bearer … → Filter 寫入 SecurityContext。
sequenceDiagram participant C as Client participant AC as AuthController participant AS as AuthService participant JWT as JwtTokenProvider participant F as JwtAuthenticationFilter participant OC as OrderController C->>AC: POST /api/auth/register AC->>AS: BCrypt + save User AS-->>C: 201 C->>AC: POST /api/auth/login AC->>AS: AuthenticationManager AS->>JWT: generateToken HS256 AS-->>C: 200 + token C->>F: Orders API + Bearer F->>JWT: validate + roles F->>F: SecurityContext F->>OC: 放行 OC-->>C: 2xx

類別：JwtTokenProvider（簽／驗）、JwtAuthenticationFilter（Header → Context）。

API — 請求路徑

  • Auth：register／login（公開）。
  • Orders：CRUD + cancel；建單冪等鍵 clientOrderId → 重複則 409。
  • 刪除僅 ADMIN；取消為狀態轉移（NEW → CANCELLED）。

詳細錯誤碼與驗證矩陣見 docs/驗證設計.md；長文流程見專案引導教學。

套件 — 類別地圖

  • 請求進 Controller → Service → Repository；安全橫切在 security／config。
  • 例外統一由 GlobalExceptionHandler 轉 JSON。
