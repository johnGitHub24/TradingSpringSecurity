TradingSpringSecurity 資料庫設計

衝突以 規格書.md 第 3 章為準。
規範：EngineeringOS knowledge/database-design.md

1. 存取鏈

Controller → Service (@Transactional) → Repository → H2

2. 資料表

表 用途 重要約束／索引
users 使用者 username UNIQUE
user_roles 角色（ElementCollection） FK → users
orders 訂單 client_order_id UNIQUE；symbol／username 索引

3. Entity 對照

Entity 表
UserEntity users（+ user_roles）
OrderEntity orders

4. 環境

Profile DB 設定
本機／預設 H2 mem tradingdb application.yml；Console /h2-console
測試 H2 application-test.yml

無 PostgreSQL／Kafka／Redis 依賴。

5. SQL 驗證

整合 Case DB-001（DatabaseSchemaIntegrationTest）驗證 users／user_roles／orders 存在。H2 Console：

SHOW TABLES;
SELECT CONSTRAINT_NAME, TABLE_NAME FROM INFORMATION_SCHEMA.TABLE_CONSTRAINTS
WHERE TABLE_NAME IN ('USERS', 'ORDERS');
