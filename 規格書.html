第 1 章　系統範圍

1.1 核心功能

# 功能 說明
1 註冊 / 登入 JWT 發放，USER / ADMIN
2 訂單 CRUD 建立、查詢、列表、取消、刪除
3 冪等下單 clientOrderId UNIQUE，重複 409
4 監控 Actuator health / metrics

1.2 不在範圍

  • Kafka、Redis、分散式快取與事件審計
  • 真實撮合與風控

1.3 技術棧

項 選型
語言 Java 21、Gradle
框架 Spring Boot 3.2、Spring MVC
資料 Spring Data JPA、H2（dev/test）
安全 Spring Security、JWT（jjwt 0.12）
API 文件 springdoc-openapi
測試 JUnit 5、Mockito、MockMvc

第 3 章　資料庫

表 說明

user_roles ElementCollection 角色
orders 訂單，client_order_id UNIQUE

整合測試：DB-001 驗證表存在。

第 4 章　API

4.1 認證

Method 路徑 成功
POST /api/auth/register 201
POST /api/auth/login 200 + JwtResponse

4.2 訂單（需 Bearer JWT，DELETE 需 ADMIN）

Method 路徑 成功
POST /api/v1/orders 201
GET /api/v1/orders 200 分頁
GET /api/v1/orders/{id} 200
PATCH /api/v1/orders/{id}/cancel 200
DELETE /api/v1/orders/{id} 204

4.3 錯誤碼

HTTP errorCode
400 VALIDATION_FAILED
401 INVALID_CREDENTIALS / 未認證
403 權限不足
404 ORDER_NOT_FOUND
409 DUPLICATE_ORDER / USERNAME_EXISTS

第 5 章　安全

機制 實作
密碼 BCrypt
Token HS256，app.jwt.secret、expiration-ms
過濾器 JwtAuthenticationFilter
Session STATELESS
授權 DELETE /api/v1/orders/** → ROLE_ADMIN

第 6 章　設定

application.yml / application-test.yml：僅 H2；JWT 置於 app.jwt。

第 7 章　測試規格

  • 單元：gradlew test（排除 @Tag("integration")）
  • 整合：gradlew integrationTest
  • 驗收：gradlew check

完整 Case ID 見 docs/測試與CI.md。

DoD

  • [ ] gradlew check 全綠
  • [ ] 建單 201、無 token 401、驗證 400、冪等 409
  • [ ] 非 ADMIN 刪除 403、ADMIN 刪除 204
  • [ ] Swagger 與 Actuator health 可存取
